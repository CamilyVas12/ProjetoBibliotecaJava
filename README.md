# Sistema de Biblioteca

## Sobre o projeto

Este projeto consiste no desenvolvimento de um Sistema de Biblioteca utilizando Java e MySQL.

O objetivo é facilitar o gerenciamento de livros, permitindo o cadastro, a consulta e o controle de empréstimos e devoluções.

## Funcionalidades

- Cadastro de livros;
- Listagem de livros;
- Empréstimo de livros;
- Devolução de livros;
- Exclusão de livros.

## Tecnologias utilizadas

- Java
- MySQL
- JDBC
- GitHub
